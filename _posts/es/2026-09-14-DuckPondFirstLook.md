## Que es Duck Pond para mi

Este juego es una de las bases para la formación de tinyrawr, la idea es empezar a tener un equipo en armonía.

Una de las primeras dificultades que hemos encontrado, es tener todos la misma idea del juego que no existe, aún haciendo dibujos en paint y explciandolo en largas llamadas de discord no conseguiamos traer una version similar de esta idea al mundo sensible.


{% include embed/youtube.html id='_V7SS0QO9Fc' %}

Así que primero intente programar conseguir una version jugable para tener algo fisico que sea igual para todos y luego lo complementamos con la creación de un Miro.
![Imagen explicativa de como usamos el miro](/assets/img/MiroImg.png)

Estoy utilizando el [plugin YARD](https://godotengine.org/asset-library/asset/4837) para intentar conseguir un trabajo más comodo a Arya (la diseñadora), por ahora esta siendo mas teórico que practico pero ya estamos emprezando a trabajar con él. Tengo dudas sobre si es mejor esto o un json con alguna herramienta de python para poder ajusar valores. No lo tengo muy claro iré tomando medidas según los resultados y opiniones de la diseñadora.

![Imagen explicativa de como usamos el miro](/assets/img/BBDD.png)

Se ha desarrollado una pool para spawnear patos para optimizar el juego, aunque aún quedan muchas más mejoras que necesitan los incrementales, ya que todo se volverá bastante loco.
