Fish & Cheese es un pequeño juego de pesca creado durante un game jam de 3 días. Desarrollado por 3 artistas y 3 programadores.

## Descripción

El movimiento fue diseñado para ser simple y funcional, priorizando la jugabilidad dentro del tiempo limitado. La mecánica de pesca usa un sistema de burbujas que atrae y captura peces.

Tambien incorporamos un pequeño sistema de inventario, para poder comercializar con los peces o venderlo para superar los requisitos que los NPCs le piden al jugador.

Fue un verdadero reto conseguir que todo funcionase lo mejor posible en 3 dias.

Play on [Itch.io](https://warpaan.itch.io/fisch-cheese)

## Post mortem

Uno de los puntos a mejorar para la siguiente JAM es tener preparados sistemas basicos, como el menu inicial, los settings y cosas así básicas. Tener esto desde un principio hace que se pueda focalizar el tiempo en las ideas que queremos traer a este videojuego nacido de un balazo.

Queria implementar un sistema de **torretas** que lanzan burbujas para automatizar el sistema de recogida, creo que en el futuro puede ser una buena idea para una demo interesante.
