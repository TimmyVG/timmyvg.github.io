# Nuestro primer intento

Hop Shop es un juego 2D donde gestionas la tienda que heredaste de tus padres. Y tendrrás que controlar a las oleadas de animales hambrientos que vienen a hacer la compra.

Este juego ha sido el primer intento de crear algo de forma independiente, contando con el arte de mi compañera War (Ángela).


## IA y Navigation

Lo más complicado que tiene este proyecto son los **npcs**, hay que pensar en los obstaculos modificables, en sus pila de tasks e intento de crowd controller.

## UI

La ui tiene intencion de ser integrada a base de aparatos u objectos intentando hacer la sensación de que tu eres el cajero. 

El primer elemento incluido fue el telefono, **el más complicado** ya que este va a tener apps para pedir los siguientes palets de comida, leer el grupo de chat del pueblo y todo lo que se nos ocurriese.

Implementar la ui fue utilizando un sistema de MVVP reactivo [tutorial que usé](https://youtu.be/0aJRmdXk8Go?si=7tVmeQWCBBs6ebay)
